# 나의 개발 인생에 지식 나무 한 그루 심기



- 나와의 약속

1. 매 주마다 알고리즘 테마를 정한다.

2. 매일 퇴근 후 1시간 운동 후, 딱 한 문제라도 좋으니 알고리즘이라는 지식 나무 한 그루를 심는다.

3. 알고리즘 테마의 원리를 이해하고 기초를 다진다.

4. 한 주간 심은 지식 나무들을 살피며, 부족한 부분과 생각을 보완하고, 더 효율적인 코드로 리팩토링하며 복습한다.

5. 매일 매일 푸는 강박보다 더 파고들며 생각해보자.



- 풀이 원칙

1. 정답의 케이스보단 항상 왜?라는 의문점을 가진다.

2. 코드 한 줄을 짜더라도 메모리 관점, 시간 복잡도를 고민한다.

3. 최소 한 달 뒤에 같은 문제를 풀었을 때, 나를 돌아볼 수 있도록 알게된 점들을 하나씩 주석으로 기록한다.
